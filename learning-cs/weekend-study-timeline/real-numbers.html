Do Real Numbers Exist?

How the real numbers are built, what "exists" means inside mathematics, how much of ℝ anyone can reach, and what the main philosophies say. This tutorial continues The Diagonal Argument.

QuestionShort answerSection
Do they exist in mathematics?Yes. Set theory proves that a complete ordered field exists, and it is unique.4–7
Is that proof absolute?No. It is relative to the axioms, and the axioms cannot prove their own consistency.8
Can we reach every real?No. Only countably many can ever be described.9
Can analysis work without them?Much of it can, in a changed form. Constructive reals are one way.10
Are they real in the world?Nobody knows. Physics uses them as a model, and no measurement can confirm them.12

1. Three meanings of "exists"

Most arguments about the reals go in circles because the two sides mean different things by "exists". It helps to separate three senses.

SenseWhat it asksExample
Inside a theoryDoes the theory prove ∃x …?ZF set theory proves that a complete ordered field exists
By constructionCan we produce it, or compute it to any accuracy?√2 yes; a typical real no
In realityIs it there, apart from our theories?Is a length in the world exactly a real number?

A yes in one sense does not give a yes in another. Sections 2–8 work in the first sense, Sections 9–10 in the second, and Sections 11–13 in the third.

2. Why the rationals are not enough

The Greeks found that the diagonal of a square has no common measure with its side. In modern terms:

Theorem 1. No rational number x satisfies x² = 2.

Proof. Suppose x = p/q in lowest terms with p² = 2q². Then p² is even, so p is even, say p = 2r. Then 4r² = 2q², so q² = 2r² and q is even too. That contradicts lowest terms. ∎

So geometry has a length with no rational number. This is more than a curiosity, because the gap breaks a basic expectation about graphs: a continuous curve that goes from below the axis to above it should cross the axis. The function x² − 2 is negative at 1 and positive at 2, and over ℚ it never equals 0. The real numbers are invented to make such crossings happen.

3. What we want: a complete ordered field

Before building anything, say what the result must do.

Definition 2. An ordered field is a set with +, ·, and < obeying the usual rules of arithmetic and order. A set S has upper bound b if s ≤ b for all s ∈ S. A number c is the least upper bound of S, written sup S, if c is an upper bound and c ≤ b for every upper bound b. An ordered field is complete if every non-empty subset with an upper bound has a least upper bound.

ℚ is an ordered field, and Proposition 14 of The Diagonal Argument shows it is not complete. Completeness is exactly what repairs the crossing problem.

Theorem 3 (intermediate value theorem). In a complete ordered field, let f be continuous on [a, b] with f(a) < 0 < f(b). Then f(c) = 0 for some c.

Proof. Let S = {x ∈ [a, b] : f(x) < 0}. S contains a and is bounded by b, so c = sup S exists. If f(c) < 0, continuity keeps f negative a little to the right of c, so c is not an upper bound. If f(c) > 0, continuity keeps f positive a little to the left of c, so a smaller number is an upper bound. Hence f(c) = 0. ∎

The question is now precise: does a complete ordered field exist? Axioms alone do not answer it, because a list of wishes can be contradictory. The next three sections answer it by building one from the rationals.

4. Construction 1: Dedekind cuts

Dedekind's idea of 1872: a place on the line is known by how it splits the rationals. So let the split itself be the number.

Definition 4. A Dedekind cut is a set L ⊂ ℚ that is non-empty, is not all of ℚ, is closed downward (if x ∈ L and y < x then y ∈ L), and has no greatest element. Let ℝ be the set of all cuts. Order cuts by L ≤ M when L ⊆ M, and add them by L + M = {a + b : a ∈ L, b ∈ M}. Multiplication is defined for positive cuts by products of positive members, and extended by signs. A rational q is identified with the cut {x ∈ ℚ : x < q}.

√2 is the cut L = {x ∈ ℚ : x ≤ 0 or x² < 2}. It has no greatest element: for s > 0 with s² < 2, the rational s′ = (2s + 2)/(s + 2) is larger and still has s′² < 2. Notice that this cut is a finite rule. It sorts any rational using integer arithmetic alone:

// cut.cpp -- sqrt(2) as a Dedekind cut: a rule that sorts every rational, using integers only
#include <cstdio>

// is p/q (q > 0) in the lower set L = { x : x <= 0 or x*x < 2 } ?
bool in_L(long p, long q) { return p <= 0 || p * p < 2 * q * q; }

int main() {
    const long tests[][2] = {{1, 1}, {7, 5}, {141, 100}, {1414, 1000}, {1415, 1000}, {71, 50}, {3, 2}};
    for (auto& t : tests)
        std::printf("%5ld/%-5ld %s\n", t[0], t[1], in_L(t[0], t[1]) ? "below sqrt(2)" : "above sqrt(2)");
}
$ g++ -std=c++17 -Wall -Wextra cut.cpp -o cut && ./cut

Checking the field rules is long but routine. The key property has a very short proof.

Theorem 5. The set of cuts is complete: a non-empty set 𝒮 of cuts with an upper bound M has least upper bound U = ⋃𝒮.

Proof. U is a cut. It is non-empty because 𝒮 is. It is not ℚ because U ⊆ M ≠ ℚ. It is closed downward because each member of 𝒮 is. It has no greatest element, because any x ∈ U lies in some L ∈ 𝒮, and L contains something larger. U is an upper bound because L ⊆ U for each L ∈ 𝒮. If M′ is any upper bound, then each L ⊆ M′, so U ⊆ M′. ∎

Where the existence claim hides. Each cut is an infinite set, and the phrase "the set of all cuts" is a subset of the power set of ℚ. That needs the power set axiom, and it includes cuts that no rule describes. Theorem 5 relies on this: a union of arbitrary cuts must be a cut in the collection. If you keep only cuts given by rules, the proof no longer works as written. Section 9 returns to this point.

5. Construction 2: Cauchy sequences

Cantor, Heine and Méray took another route in 1872: a number is what a sequence of better and better approximations is approaching.

Definition 6. A sequence (xₙ) of rationals is Cauchy if for every rational ε > 0 there is N with |xₘ − xₙ| < ε for all m, n ≥ N. Two Cauchy sequences are equivalent if xₙ − yₙ → 0. A real number is an equivalence class, and arithmetic is done term by term.

Equivalence is needed because many sequences approach the same place. Here is one for √2, in exact fractions, from x′ = (x + 2/x)/2:

// newton.cpp -- a Cauchy sequence of rationals for sqrt(2): x' = (x + 2/x) / 2, in exact fractions
#include <cstdio>

using big = __int128;
void show(big v) {                      // printf has no %d for __int128
    if (v < 0) { std::putchar('-'); v = -v; }
    if (v >= 10) show(v / 10);
    std::putchar('0' + int(v % 10));
}

int main() {
    big p = 1, q = 1;                   // x = p/q
    for (int n = 1; n <= 6; ++n) {
        std::printf("x%d = ", n); show(p); std::putchar('/'); show(q);
        std::printf("   x^2 - 2 = "); show(p * p - 2 * q * q); std::putchar('/'); show(q * q);
        std::printf("   about %.3g\n", double(p * p - 2 * q * q) / double(q * q));
        big np = p * p + 2 * q * q, nq = 2 * p * q;   // (p/q + 2q/p) / 2
        p = np; q = nq;
    }
}
$ g++ -std=c++17 -Wall -Wextra newton.cpp -o newton && ./newton

Every term is a fraction, and by Theorem 1 no term is √2. The sequence converges very fast, because x′² − 2 = ((x² − 2)/(2x))², so the error is roughly squared at each step. The output shows the pattern: 1/4 gives 1/144, and that gives 1/166464.

Theorem 7. The equivalence classes of rational Cauchy sequences form a complete ordered field.

Sketch. Sums and products of Cauchy sequences are Cauchy. A sequence that does not tend to 0 is eventually bounded away from 0, so it has an inverse, which gives a field. A class is positive if its terms are eventually above some positive rational. For completeness, bisect from an upper bound and a lower bound of S: the midpoints form a Cauchy sequence whose class is sup S. ∎

6. Construction 3: decimals, and why they are awkward

Decimals look like the obvious definition: a real is an integer with an infinite digit sequence, with 0.4999… identified with 0.5. The definition works, but arithmetic is awkward. To add, you start from the right, and an infinite decimal has no right end.

Take x = 0.3333… and y = 0.6666…. What is the first digit of x + y? If the digits stay 3 and 6 forever, the sum is 0.9999… = 1. If one later digit rises, the sum passes 1, and if one falls, the sum stays below 1. No finite number of digits decides even the first digit. This is a preview of Section 10: real numbers given only by approximations resist exact decisions.

7. All constructions agree

Theorem 8. Any two complete ordered fields are isomorphic: there is exactly one bijection between them that preserves +, · and <.

Sketch. Every ordered field contains a copy of ℚ. Completeness forces the Archimedean property, so each element x is determined by the rationals below it. Send x in the first field to the supremum, in the second field, of those same rationals. This map preserves the operations, and any such map must equal it. ∎

So there is only one complete ordered field, up to renaming. Is √2 "really" a set of rationals, or a class of sequences? Theorem 8 says the question has no mathematical content. Only the structure matters. This is the idea behind structuralism, and it goes back to Benacerraf's 1965 argument that numbers are not particular objects at all.

8. What this existence proof does and does not show

Sections 4–7 prove: ZF set theory proves that a complete ordered field exists, and that it is unique. That is a real theorem, and it is the standard meaning of "the reals exist". It has three limits.

It is relative. The proof moves the question from ℝ to set theory. If ZF is inconsistent, the theorem means nothing. By Gödel's second incompleteness theorem, ZF cannot prove its own consistency, if it is consistent. So there is no absolute proof from within, and confidence rests on a century of use with no contradiction found.

"All subsets" does heavy work. Completeness speaks of every subset of ℝ, a second-order statement. First-order statements cannot capture it. Tarski showed that the first-order theory of ℝ as an ordered field is complete and decidable, and that the real algebraic numbers, a countable set, satisfy exactly the same first-order sentences. So no first-order sentence about + , · and < can tell ℝ from that countable field.

"Uncountable" is relative too. By the Löwenheim–Skolem theorem, if ZF has a model, it has a countable one. Inside that model, ℝ is uncountable, because the model contains no bijection between its ℕ and its ℝ. From outside, its ℝ has only countably many members. This is Skolem's paradox. It is no contradiction, but it shows that the meaning of "all subsets" is not fixed by the first-order axioms alone.

9. How much of ℝ can anyone reach?

Every layer but the last is countable, because each member has a finite description. (The last-but-one layer is counted from outside the language.) By the diagonal argument, the reals are not, so in the classical picture almost every real lies in the last layer.

A real is computable if a program, given n, prints an approximation within 10⁻ⁿ. All numbers used in practice are computable. Two facts mark the limits of this layer.

Definable but not computable. Number all programs, and let h = Σ 2⁻ⁿ, summed over the n for which program n halts on empty input. This is a perfectly precise definition, but computing h would solve the halting problem. Chaitin's Ω is a more refined number of this kind.

The computable reals are not complete. Specker showed in 1949 that there is a computable, increasing, bounded sequence of rationals whose limit is not computable. So the computable reals have gaps in the classical sense. This is why you cannot simply replace ℝ by the computable reals and keep the same theorems. You have to change the theorems too, which is what constructive analysis does.

10. The constructive reals

Constructive mathematics reads "there exists" as "we can construct". A proof of an existence claim must contain a method. Bishop's version needs no philosophy beyond that, and classical mathematics counts as a model of it, so every constructive theorem is also a classical one.

Definition 9 (Bishop). A real number is a sequence (xₙ) of rationals with |xₘ − xₙ| ≤ 1/m + 1/n for all m, n ∈ ℕ. The convergence rate is part of the definition, so the sequence itself tells you how accurate each term is.

Some classical statements cannot be proved in this sense, for a clear reason. Let (aₙ) be a binary sequence and put x = Σ aₙ2⁻ⁿ. To decide "x = 0 or x ≠ 0" you must decide whether every aₙ is 0. Let aₙ = 1 if the even number 2n + 2 is a counterexample to Goldbach's conjecture, and aₙ = 0 otherwise. Then deciding x = 0 would settle Goldbach. A general method would give the limited principle of omniscience (LPO): for every binary sequence, either all terms are 0 or some term is 1. Constructive mathematics does not accept LPO.

Classical statementConstructive status
Every x has x = 0 or x ≠ 0Implies LPO, so it is not provable
Intermediate value theorem (Theorem 3)Implies a weaker omniscience principle, LLPO. The provable form says: for every ε > 0 there is an x with |f(x)| < ε. Under extra conditions, such as f being locally non-zero, an exact root exists.
Every bounded non-empty set has a least upper boundEquivalent to the law of excluded middle. It holds for sets that are "upper-order located", a condition that gives a way to approximate the bound.

The replacements are often what an engineer wants anyway. The approximate intermediate value theorem is what a root-finding program can actually deliver.

Brouwer's intuitionism goes further. It allows free choice sequences that are never finished, and it proves that every function from ℝ to ℝ is continuous. That contradicts classical mathematics, so unlike Bishop's system it is a rival theory, not a part of the classical one. Markov's recursive school takes reals to be given by algorithms, and in that setting LPO is refuted.

11. What the philosophies say

PositionDo the reals exist?Who
PlatonismYes: abstract objects, outside space and time, independent of usGödel
FormalismThe question is about a consistent formal system, nothing moreHilbert
StructuralismThe structure exists; individual numbers are only positions in itBenacerraf, Shapiro
PredicativismThose definable without quantifying over all reals. ℕ is accepted, "all subsets" is not.Weyl (1918), Feferman
ConstructivismThose we can constructBishop
IntuitionismThose constructible in the mind, including unfinished choice sequencesBrouwer
FictionalismNo. Mathematics is a useful story, and it need not be true.Field
FinitismNo completed infinite objects, so no reals as usually understoodKronecker; Wildberger

The best argument for existence is the Quine–Putnam indispensability argument. Whatever is indispensable to our best science is likely to be true, and mathematics is indispensable to science. So we should accept the objects it talks about.

The best argument against platonism comes from Benacerraf (1973), as sharpened by Field. Mathematicians are reliable, so there must be some explanation of that reliability. If numbers are outside space and time and cause nothing, no explanation seems possible.

12. Are real numbers in the world?

Physics writes its laws with real numbers, which tempts us to think space and time are made of them. There are reasons for caution.

  • Every measurement has finite precision, so no experiment can show that a quantity has infinitely many meaningful digits.
  • A real number can hold unlimited information. Borel noted that one number could encode the answers to all yes-or-no questions. Nicolas Gisin has argued that this makes classical physics look more deterministic than it is, and has proposed physics with finite-information quantities.
  • Chaitin has suggested that reality may be discrete. Edward Lee replies that this cannot be tested either.

On the other side, the continuum models work with extraordinary success, and quantum theory is formulated over real and complex numbers. Models that work do not settle the question, though, because a discrete world could look continuous at our scale, as water does. At present this is open, and it may stay open.

13. Wildberger's objections

N. J. Wildberger is the best-known current critic, in posts such as "The problem of the continuum" and "Difficulties with real numbers". In a comment on the first post he says plainly: "I don't believe in "irrational numbers" at all." His main arguments:

  • Cuts, Cauchy sequences and continued fractions all talk about infinite objects without saying how to specify them.
  • An infinite sequence can only be given by a rule, so a theory of reals needs a prior theory of algorithms, which he says we lack.
  • Nobody can exhibit an uncomputable real, although measure theory says they are almost all of [0, 1].
  • "Let α be a real number" pretends to choose something that cannot be chosen.
  • Axiomatics removed the duty to define objects before using them.

These comments, like those in the next section, are from Claude.

Where he is right. The specification problem is real, and it is exactly the layer picture of Section 9. It is also true that textbooks often pass over this, and that "the set of all cuts" asks for far more than any rule delivers.

Where I disagree. A theory of algorithms exists: Turing and Church gave one in 1936, and Bishop's analysis handles specification with care. "Let α be a real number" does not choose anything. It is how we say "for all α", and a proof that uses only the axioms works for all of them. On uncomputable reals, the halting number h of Section 9 has an exact definition. If "example" means "a program", then the claim that there are no examples is true by definition, and it is the theorem of computability theory rather than an objection to it. Finally, the classical theory does not hide its assumptions: they are the axioms of Section 8. They can be rejected, but the rejection needs a replacement that covers analysis. Wildberger's work on rational trigonometry and algebraic calculus is interesting, and it has a long way to go to do that.

14. A view

Going back to the three senses of Section 1:

  • Inside a theory, yes. This is a theorem, relative to ZF. Anyone who works in that theory may say "ℝ exists" without embarrassment.
  • By construction, partly. Every real that has ever been used is in the countable layers. The rest are a consequence of the phrase "all subsets".
  • In reality, unknown. No measurement can decide it, and neither can any proof.

The classical reals are best seen as an idealisation, like a frictionless plane. They have no gaps, so theorems are short. Whether they exist in the third sense matters less to using them than the debate suggests, though it matters a great deal to what mathematics is about.

16. Check yourself

1. In Theorem 5, where is the phrase "all cuts" used?

U = ⋃𝒮 must itself be in the collection. Since 𝒮 can be any bounded set of cuts, the collection must contain every such union.

2. Check x′² − 2 = ((x² − 2)/(2x))² for x = 3/2.

x′ = 17/12, so x′² − 2 = 1/144. On the right, x² − 2 = 1/4 and 2x = 3, so (1/12)² = 1/144.

3. Why doesn't Theorem 8 contradict Skolem's paradox?

Theorem 8 is proved inside a model of set theory: within that model, the complete ordered field is unique. Different models can disagree on which subsets exist, so they can have different collections of reals.

4. Is every computable real algebraic?

No. π and e are computable and not algebraic.

5. Why is "x = 0 or x ≠ 0" fine for rationals, constructively?

A rational is given by two integers, and deciding whether an integer is 0 takes finite work.

6. Which sense of "exists" does each of these use: Theorem 5; Bishop's Definition 9; the indispensability argument?

Inside a theory; by construction; in reality.
