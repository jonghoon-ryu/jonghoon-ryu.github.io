The Diagonal Argument

Why there are more real numbers than whole numbers, what the continuum is, and whether numbers and points are the same thing.

1. What "how many" means for infinite sets

You cannot count an infinite set to the end, so compare sets without counting. A theatre has as many seats as people if every person sits in one seat and no seat is empty. No number is needed.

Same size means this: the two sets can be paired one to one, with nothing left over on either side. Such a pairing is called a bijection.

Infinite sets behave strangely under this rule. The even numbers can be paired with all the whole numbers, 1↔2, 2↔4, 3↔6, and so on. A part can be the same size as the whole. Keep that in mind: the rule is about pairing, not about one set looking larger.

2. Countable sets

A set is countable if it can be written as a list: first item, second item, third item, with every member appearing at some finite position. A list is exactly a pairing with 1, 2, 3, …

The integers are countable: 0, 1, −1, 2, −2, 3, −3, … The fractions are countable too, which surprises most people, because between any two fractions there are infinitely many more. The trick is to choose the order yourself.

// rationals.cpp -- list the positive rationals by walking the diagonals p + q = 2, 3, 4, ...
#include <cstdio>
#include <numeric>

int main() {
    int n = 0;
    for (int sum = 2; n < 20; ++sum)
        for (int p = 1; p < sum && n < 20; ++p) {
            int q = sum - p;
            if (std::gcd(p, q) != 1) continue;      // 2/4 is 1/2, already listed
            std::printf("%d/%d ", p, q);
            if (++n % 10 == 0) std::printf("\n");
        }
}

5/1 1/6 2/5 3/4 4/3 5/2 6/1 1/7 3/5 5/3

So being dense, with no two neighbours, does not make a set large. That makes the next result more striking.

3. The diagonal argument

Theorem. The real numbers between 0 and 1 are not countable. No list contains them all.

The proof takes any list at all, and builds a real number that the list misses.

  1. Take any list x₁, x₂, x₃, … of reals in (0, 1), and write each as a decimal.
  2. Look at the n-th digit of the n-th number, the diagonal.
  3. Build y = 0.e₁e₂e₃… with eₙ = 6 if the diagonal digit is 5, and eₙ = 5 otherwise.
  4. y differs from x₁ at digit 1, from x₂ at digit 2, and from every xₙ at digit n.
  5. So y is a real in (0, 1) that is not on the list.

Since this works for every list, no list is complete. There is no contradiction to wait for and no assumption to take back: the proof is a recipe that turns any list into a counterexample.

4. The trap: numbers with two decimals

Different digits usually mean different numbers, but not always. 0.5000… and 0.4999… are the same number. A careless proof that says "change each digit to anything else" could produce a y that equals a number on the list while differing from its written digits.

That is why the rule uses only 5 and 6. Two decimal forms happen only when one form ends in all 0s and the other in all 9s. y has no 0s or 9s, so y has only one form, and neither form of any xₙ can match it. If xₙ has two forms, use the form that appears in the list for the diagonal digit: y still differs from it at digit n, and the other form ends in 0s or 9s, which y never does.

The same proof with 0, 1 sequences

Many books avoid the trap completely. They run the diagonal on sequences of 0s and 1s, where it has no decimal problem, and only then move to numbers. This is also closer to how Cantor wrote it in 1891.

Step 1: the sequences are uncountable. Let S be the set of all infinite sequences of 0s and 1s. Take any list s₁, s₂, s₃, … of members of S, and flip the diagonal:

s₁ = 0 1 1 0 1 …
s₂ = 1 1 0 0 0 …
s₃ = 0 0 0 1 1 …
s₄ = 1 0 1 1 0 …
s₅ = 0 1 0 0 1 …

t  = 1 0 1 0 0 …      t(n) = 1 − sₙ(n)

t differs from sₙ at position n, so t is not on the list. Here different entries really do mean different sequences, so there is nothing to patch.

Step 2: map the sequences into the reals. Read each sequence as a decimal that uses only the digits 0 and 1:

f(s) = 0.s(1)s(2)s(3)…      for example  f(0, 1, 1, 0, 1, …) = 0.01101…

Different sequences give different numbers. Suppose s and t first differ at position k. That makes a difference of 10⁻ᵏ, and all the later digits together can change the value by at most 10⁻ᵏ/9, which is smaller. So f(s) ≠ f(t).

Base 10 matters here. Reading the digits in base 2 would fail, because 0.0111…₂ and 0.1000…₂ are the same number, and the trap would come back.

Step 3: conclude. Suppose the reals could be listed. Go down that list, keep only the numbers of the form f(s), and replace each by its s. Since f never sends two sequences to one number, this lists all of S, which Step 1 says is impossible. So the reals are uncountable.

Why the map goes to the reals and not the rationals. The rationals are countable (Section 2), so S cannot be mapped into them without two sequences landing on the same fraction. Rationals do appear in two other places, which may be what you remember:

  • Some sequences land on rationals. Under f, a sequence that eventually repeats gives a rational: (1, 0, 1, 0, …) gives 0.1010… = 10/99. A sequence that never repeats gives an irrational.
  • Each real gives a 0, 1 sequence over the rationals. List the rationals q₁, q₂, q₃, … and give a real r the sequence with 1 at position n if qₙ < r, and 0 otherwise. This is Dedekind's cut written as a sequence. Two different reals have a rational between them, so they get different sequences.

The second map runs in the opposite direction to f, so each set fits inside the other. By the Schröder–Bernstein theorem, ℝ and S have exactly the same size, which is why 𝔠 = 2ℵ₀ in Section 7.

5. Run it

A computer can only hold a finite list, so this is a demonstration, not a proof. It does show the recipe working on actual decimals, and the list includes the trap from Section 4.

// diagonal.cpp -- build a number that is not on a given list of decimals
#include <cstdio>
#include <string>
#include <vector>

int main() {
    // digits after "0." of each number on the list; any list works
    std::vector<std::string> list = {
        "50000000",   // 0.5
        "49999999",   // the start of 0.4999..., the same number as 0.5
        "33333333",   // 1/3
        "14159265",   // the digits of pi after the 3
        "71828182",   // the digits of e after the 2
        "41421356",   // the digits of sqrt(2) after the 1
        "12345678",
        "55555555",   // 5/9
    };
    std::string y;
    for (std::size_t n = 0; n < list.size(); ++n)
        y += (list[n][n] == '5') ? '6' : '5';       // the 5/6 rule

    for (std::size_t n = 0; n < list.size(); ++n)
        std::printf("x%zu = 0.%s   digit %zu is %c, y has %c\n",
                    n + 1, list[n].c_str(), n + 1, list[n][n], y[n]);
    std::printf("y  = 0.%s...\n", y.c_str());

    for (std::size_t n = 0; n < list.size(); ++n)
        if (y[n] == list[n][n]) std::printf("FAIL at %zu\n", n + 1);
    std::printf("y differs from every x in its own position\n");
}

6. Objections, answered

ObjectionAnswer
Just add y to the list.That gives a new list, and the recipe gives a new y. The theorem is about every list, including the improved one.
y is never finished.Every digit is fixed by a rule, so the partial decimals 0.6, 0.65, 0.655, … converge. Completeness of ℝ (Section 7) gives their limit. The proof does not need anyone to write y out.
The list is infinite too, so y could be further down.y cannot be at position n for any n, because it differs from that entry at digit n. Every position is a finite number.
The same trick would prove the fractions uncountable.It would not. y is real but need not be a fraction, so missing a list of fractions proves nothing. Section 2 shows that list exists.
It would prove the whole numbers uncountable.Applied to whole numbers, y would have infinitely many digits, and that is no whole number.

7. What is the continuum?

The word comes from the Latin for "holding together". It has three meanings, and most confusion comes from sliding between them.

Meaning 1: the idea

The continuum is the line, time or motion as we experience it: unbroken, with no jumps, and divisible without end. Aristotle argued that a continuous thing is divisible into parts that are always divisible again, so that it cannot be built from indivisible pieces. On this view a line is primary, and a point is only a place where you could cut it.

Meaning 2: the structure

In the 1870s mathematicians turned the idea into properties. An ordered set is a linear continuum if it has these two:

  • Dense: between any two members there is another.
  • Complete: no gaps. Every non-empty set with an upper bound has a least upper bound.

The fractions are dense but not complete. The fractions whose square is below 2 have upper bounds, but no least one among the fractions: the place where it should be, √2, is a hole. Dedekind's insight in 1872 was that this gap property is the precise meaning of continuity.

Meaning 3: the size

Set theorists also call the size of ℝ "the continuum", written 𝔠. It equals 2ℵ₀, the number of infinite sequences of 0s and 1s, and the diagonal argument says 𝔠 is larger than ℵ₀, the size of the whole numbers.

Is any size strictly between them? The claim that none exists is the continuum hypothesis. Gödel (1940) and Cohen (1963) showed that the usual axioms of set theory cannot prove it or refute it.

Size and structure are different things. The Cantor set below has the full size 𝔠, yet it is mostly gaps and has total length 0. It has as many points as the line and none of its continuity.

8. Are the real numbers the same as the continuum?

It depends on the meaning.

MeaningAre the reals it?
The size 𝔠Yes, by definition.
The structureYes, in the classical sense: ℝ is the only complete ordered field, up to renaming. As an order alone it is characterised by Cantor: a complete dense order with no endpoints and a countable dense subset.
The ideaThis is an open philosophical question. ℝ is the standard model, and a model can fit well without being the thing itself.

The reals are not the only serious candidate. Each of these keeps a different part of the idea:

ModelWhat differs from ℝ
Hyperreals (Robinson, 1960s)Contains infinitely small numbers. It gives up completeness in the sense of Section 7.
Brouwer's intuitionistic continuumNumbers grow as choice sequences that are never finished. The continuum cannot be split into two separate parts, and every total function on it is continuous.
Bishop's constructive reals (1967)A real is given by a rule that produces approximations. Most of analysis survives, with some theorems reworded.
Smooth infinitesimal analysisA line contains nilsquare infinitesimals, numbers ε with ε² = 0, and the logic is not classical.

So the fair statement is this: the real numbers are the classical mathematical model of the continuum. Their great success is a good reason to use them. It is not a proof that the intuitive continuum is made of them.

9. Are real numbers the same as points?

No. They are two kinds of thing, joined by a choice and an assumption.

The choice. A geometric line has no special place. Numbers do: 0 and 1 behave unlike every other number. To number a line you must pick an origin, a unit and a direction. Pick differently and the same point gets a different number. A point has no number of its own.

The assumption. Even with those choices made, it takes an axiom to say that every point has exactly one real number and every real number has exactly one point. This is the Cantor–Dedekind axiom. Dedekind said plainly that he could not prove it: he assumed it about the line, and he added that space itself need not be continuous.

The two also carry different structure:

Real numbersPoints on a line
Add, multiplyYesNot without a chosen origin and unit
Special members0 and 1None
Basic relationOrder and arithmeticBetweenness and equal lengths
Where it comes fromBuilt from fractions, by Dedekind cuts or Cauchy sequencesGeometry, taken as given

There is an older question underneath: is a line made of points at all? Euclid treats points as the ends of lines, and Aristotle denied that a line is composed of them. Modern set theory defines a line as a set of points, because that is convenient. It is a modelling decision. Pointfree topology builds geometry from regions and treats points as derived, so the mathematics does not depend on the decision.

10. How can zero-length points make a line of length 1?

Lawrence Spector's "Is a line really composed of points?" presses this objection, and it deserves an answer. Each point has length 0. Adding 0s should give 0. Yet the line has length 1.

The answer in measure theory is that length adds over countably many pieces, and no further. Length is assigned to the interval as a whole. It is never worked out by adding up points, so there is no sum of uncountably many 0s anywhere in the theory, and no division by 0.

This gives a second proof of the theorem, with no decimals. Suppose [0, 1] could be listed as x₁, x₂, … Cover x₁ with an interval of length 1/4, x₂ with length 1/8, x₃ with length 1/16, and so on. The total length is 1/2, but the intervals would cover all of [0, 1], whose length is 1. Compactness of [0, 1] (the Heine–Borel theorem) makes that impossible. A countable set has length 0, so the interval must be uncountable.

Whether this answers the objection or only sets a rule that avoids it is a matter of opinion. Spector says the theory has changed the meaning of "composed". He has a point: the "composition" of a line from points is not like a wall made of bricks.

11. Numbers without names

Every name, formula or program is a finite string of symbols, so they can be listed. The reals cannot. So if all the reals exist, almost all of them have no name, and nobody could ever point to one. It is reasonable to find that hard to accept.

First, notice what the diagonal proof actually does. It never produces an unnamed number. Given a list, it names y: "the diagonal of this list, with each digit changed". The step from "no list is complete" to "nameless numbers exist" comes from elsewhere. Here are the two main readings.

Classical readingConstructive reading
What a real isAny infinite digit sequence, rule or no ruleSomething given by a rule
What the proof showsA completed totality bigger than any listNo procedure can list all the reals
Unnamed realsAlmost all of themNone are needed

The constructive reading has a neat example. The computable reals are those whose digits some program can print. There are only countably many programs, yet the diagonal argument shows that no program can list exactly the computable reals: if one could, y would be computable too. "Uncountable" here means "cannot be exhausted by any listing procedure", and no nameless objects are involved.

The classical side is also less solid than it sounds. "Definable" cannot be defined inside the same language without paradox; that is Richard's paradox of 1905. And there are models of set theory in which every real is definable, so "some real has no definition" is not a theorem that set theory can state and prove in that form. The counting argument is made from outside the system.

So unnamed numbers are a consequence of a choice of axioms, not a discovery. The classical choice gives short theorems, such as the least upper bound property. You can use that theory fully and still doubt that the unnamed reals are "there". Edward Lee's "Are Real Numbers Real?" discusses this through Chaitin's doubts.

12. The same trick elsewhere

The pattern is always the same: a table of things against things, and a new row made by changing the diagonal.

14. Check yourself

1. Write the proof on a blank page, with the 5 and 6 rule. Why not change each digit to "anything else"?

Because y could then end in 0s or 9s and equal a listed number in its other decimal form, for example 0.5000… and 0.4999….

2. Are the algebraic numbers (roots of integer polynomials) countable?

Yes. There are countably many polynomials, each with finitely many roots. So there are real numbers that are not algebraic, which is Cantor's proof that transcendental numbers exist.

3. Run the proof in binary. What goes wrong with "flip each bit"?

The same trap: 0.0111…₂ = 0.1000…₂. It works directly for infinite 0-and-1 sequences, which are not numbers and have no such duplicates. That is the form Cantor used.

4. Why is ℚ not a continuum, even though it is dense?

It is not complete. The set of fractions with square below 2 is bounded but has no least upper bound in ℚ.

5. The Cantor set has size 𝔠 and length 0. Which of the three meanings of continuum does it satisfy?

Only the size. It has gaps, so it is no continuum as a structure or as an idea.

6. Does the diagonal argument prove that a number with no name exists?

No. It shows every list misses something, and the number it builds has a description in terms of that list. The further step needs the classical idea that all digit sequences exist.

15. Three articles worth reading

These three pages started this tutorial. The comments are opinions from Claude, the AI that helped write this page, and you may well disagree. None of the three says the diagonal proof is wrong: Spector does not discuss it, and Lee uses it.

Lawrence Spector, "Is a line really composed of points?"

What it says. A line is not made of points. Infinitely many zero-length points cannot add up to a positive length, and time cannot be made of instants, or nothing could move. He concludes that "Points exist potentially", like the pitches on a guitar string that exist only when played.

Where it is strong. It asks a question that many textbooks skip, and it stands in a tradition going back to Aristotle. It is right that "composed" means something unusual in set theory, since a line is not built from points the way a wall is built from bricks.

Where I disagree. The charge that the theory divides by 0 misses its target. Measure theory never adds up the points, as Section 10 shows. The motion argument is also weaker than it looks: calculus treats motion as a function of time, and velocity as a limit, so a moving thing needs no "motion within an instant". And "Calculus has no need for anything more" goes too far. Calculus needs something like completeness, because over the fractions alone x² − 2 goes from negative to positive without ever being 0. His picture is a fair philosophy of the line, but it is not yet a replacement theory.

Lawrence Spector, "Rational and irrational numbers"

What it says. We know irrational numbers only through rational approximations. "The decimal for an irrational number is always inexact", and a decimal that never ends is "nothing but a thought". For such a decimal to count as a number at all, there must be a rule that computes each digit.

Where it is strong. It is a healthy reminder that nobody has ever written down an infinite decimal. Its demand for a rule is close to the constructive view of Section 11, and it comes close to the answer to "how can unnamed numbers exist?": on this view, they do not.

Where I disagree. It treats the decimal as if it were the number. A decimal is only one way of writing a number. √2 is known exactly: it is the positive solution of x² = 2, and the ratio of a square's diagonal to its side. What is inexact is a finite decimal for it. Also, the dividing line between rational and irrational is repetition, not pattern: 0.101001000100001… has an obvious pattern and is irrational.

Edward A. Lee, "Are Real Numbers Real?"

What it says. Lee reviews Gregory Chaitin's case against the reals: Borel's single number that encodes all knowledge, the limits on what any noisy channel can tell us, and Richard's paradox. He accepts these results, but rejects Chaitin's conclusion that the world is discrete. In his view that hypothesis cannot be falsified, so it is not science.

Where it is strong. This is the best of the three. It separates what we can know from what exists, and it does not claim more than it can show. It also takes the diagonal argument and the gap between countable languages and the uncountable continuum seriously.

Where I disagree. The test cuts both ways. If digital physics cannot be falsified, neither can the claim that physical reality is truly continuous, and Lee's own defence ends in a Platonic heaven and "a matter of faith". That is an honest ending, but it makes the two sides level, with neither one winning. His reading of Richard's paradox could also be sharper. I would say it shows that "definable" cannot be defined inside the same language, a precise result that holds for formal languages too, rather than a defect of written language.
