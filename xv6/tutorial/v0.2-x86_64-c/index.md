# `v0.2-x86_64-c` : 화면 콘솔과 PS/2 키보드

| | |
|---|---|
| **앞 태그** | `v0.1-x86_64-c` |
| **이 태그** | `v0.2-x86_64-c` (커밋 `7829294`), 브랜치 `main` 의 지금 |
| **한 줄** | 시리얼 포트만 있던 입출력에 **화면** (UEFI 프레임버퍼) 과 **PS/2 키보드** 를 더했다. VirtualBox 창에서 바로 셸을 쓸 수 있다 |
| **중요** | C++ 판의 각 단계 (`step-01` …) 는 **이 태그와 비교** 한다. 화면·키보드 코드가 여기에만 있다 |

```sh
git diff --stat v0.1-x86_64-c v0.2-x86_64-c -- . ':!docs'
git checkout v0.2-x86_64-c && make clean && make vbox      # VirtualBox 창에서 쳐 보기
```

## 1. 이전 상태 : 시리얼만 (`v0.1`)

`v0.1` 은 모든 입출력이 시리얼 포트 (COM1) 를 거친다. QEMU 는 터미널이 곧 시리얼이라 괜찮지만, **화면에는 로더의 마지막 줄에서 멈춘 그림** 만 남는다.
셸은 시리얼에서만 돌고 있다 :

![v0.1 의 QEMU 화면 : 셸은 떠 있지만 시리얼에만 보인다](/assets/image/xv6-tut-v01-qemu-screen.png)

VirtualBox 에서는 창이 까맣고, `socat` 으로 시리얼 소켓에 붙어야 셸을 쓸 수 있었다. 시리얼 포트가 없는 실제 PC 에서는 아무것도 볼 수 없다.

로더는 `v0.1` 에서 이미 화면 정보 (`bootinfo.fb_base`, `fb_width`, …) 를 넘겨주고 있었다. 쓰는 쪽이 없었을 뿐이다.

drawchar(int col, int row, int c)
{
  c &= 0x7f;
  for (int j = 0; j < cons.charh; j++) {
    uint *p = cons.fb + (row * cons.charh + j) * cons.stride + col * cons.charw;
    uint bits, top;
    if (cons.charw == 32) {
      bits = font32x64[c][j];
      top = 0x80000000;
    } else {
      bits = font16x32[c][j];
      top = 0x8000;
    }
    for (int i = 0; i < cons.charw; i++)
      p[i] = (bits & (top >> i)) ? FG : BG;

}

```cpp
fbconsputc(int c)
{
  if (cons.fb == 0)
    return;

  // printk() may be called during a panic with locks held;
  // don't risk waiting for this lock then.
  int locked = 0;
  if (!panicking) {
    acquire(&cons.lock);
    locked = 1;
  }

  cursor(BG);
  if (c == '\n') {
    cons.cx = 0;
    cons.cy++;
  } else if (c == '\r') {
    cons.cx = 0;
  } else if (c == '\b') {
    if (cons.cx > 0)
      cons.cx--;
  } else if (c == '\t') {
    cons.cx = (cons.cx + 8) & ~7;
  } else {
    drawchar(cons.cx, cons.cy, c);
    cons.cx++;
  }
  if (cons.cx >= cons.cols) {
    cons.cx = 0;
    cons.cy++;
  }
  if (cons.cy >= cons.rows) {
    scroll();
    cons.cy = cons.rows - 1;
  }
  cursor(FG);

  if (locked)
    release(&cons.lock);
}
```

### 2.2 PS/2 키보드 (`kbd.c`, `kbd.h` 새 파일, `trap.c`, `main.c`)

옛 x86 판 xv6 (xv6-public) 의 키보드 드라이버를 가져왔다. 키보드는 글자가 아니라 **스캔 코드** 를 보낸다 : 누를 때 하나 (`a` = `0x1E`), 뗄 때 `0x80` 을 더한 것 (`0x9E`).

[`kernel/kbd.c:62–99`](https://github.com/jonghoon-ryu/xv6-x86_64/blob/v0.2-x86_64-c/kernel/kbd.c#L62-L99) (태그 `v0.2-x86_64-c`)

```cpp
kbdgetc(void)
{
  static uint shift;
  static uchar *charcode[4] = {normalmap, shiftmap, ctlmap, ctlmap};
  uint st, data, c;

  st = inb(KBSTATP);
  if ((st & KBS_DIB) == 0)
    return -1;
  data = inb(KBDATAP);
  if (st & KBS_AUX)
    return 0; // a mouse byte, in case the mouse is still on

  if (data == 0xE0) {
    shift |= E0ESC;
    return 0;
  } else if (data & 0x80) {
    // Key released
    data = (shift & E0ESC ? data : data & 0x7F);
    shift &= ~(shiftcode[data] | E0ESC);
    return 0;
  } else if (shift & E0ESC) {
    // Last character was an E0 escape; or with 0x80
    data |= 0x80;
    shift &= ~E0ESC;
  }

  shift |= shiftcode[data];
  shift ^= togglecode[data];
  c = charcode[shift & (CTL | SHIFT)][data];
  if (shift & CAPSLOCK) {
    if ('a' <= c && c <= 'z')
      c += 'A' - 'a';
    else if ('A' <= c && c <= 'Z')
      c += 'a' - 'A';
  }
  return c;
}
```

`shift` 는 Shift, Ctrl, Alt, Caps Lock 의 상태를 비트로 기억한다. 스캔 코드는 네 표 (`normalmap`, `shiftmap`, `ctlmap`, `ctlmap`) 중 하나에서 글자로 바뀐다.
xv6-public 판에 없던 것 하나를 더했다 : `KBS_AUX` 검사 (마우스 바이트면 버림). UEFI 가 PS/2 마우스를 켜 둔 채 넘겨줄 수 있기 때문이다.

### 2.3 VirtualBox 창 (`vbox.sh`)

`make vbox` 의 기본이 headless (창 없음) 에서 **창 있음** 으로 바뀌었다. 화면 크기 2560 × 1440 (`EfiGraphicsResolution`), 시리얼은 소켓 대신 파일 `vbox/serial.log`.
