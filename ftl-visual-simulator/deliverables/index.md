# 개발 산출물

FTL 시각화 시뮬레이터를 실제로 만들어가면서 나오는 산출물( 화면 설계, 빌드 결과, 배포본 등 )을 모아두는 카테고리.

**코드 저장소** : [github.com/jonghoon-ryu/ftl-visual-simulator](https://github.com/jonghoon-ryu/ftl-visual-simulator) — Vite+React+TS 앱 뼈대와, MIT 라이선스인 [MQSim](https://github.com/CMU-SAFARI/MQSim) 소스를 `engine/mqsim` 아래 vendoring 한 초기 스캐폴드( Session 3, 정적 목업 단계 — WASM 엔진 연동 전 )가 올라가 있음.
