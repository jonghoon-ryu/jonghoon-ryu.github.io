# 플래시 칩과 PHY 깊이 보기

TSU 가 "이 transaction 을 이 칩에" 라고 정하면, 그 다음은 **PHY**(`NVM_PHY_ONFI_NVDDR2`, 707줄)와 **칩**(`Flash_Chip`, 297줄)이 시간을 쓴다. FTL 의 모든 결정이 결국 여기서 "몇 µs" 로 환산된다.

PHY 의 이벤트(`NVDDR2_SimEventType`)가 이 구간들을 잇는다 (`NVM_PHY_ONFI_NVDDR2.cpp:345`).

| 이벤트 | 의미 | 다음 |
|---|---|---|
| `READ_CMD_ADDR_TRANSFERRED` | read 의 명령·주소 전송 끝 | 채널 IDLE, 칩 READING (array 가 읽는 중) |
| (칩 완료) → `READ_DATA_TRANSFERRED` | 읽은 data 를 채널로 내보내기 끝 | "트랜잭션 완료" 신호 방송 |
| `PROGRAM_CMD_ADDR_DATA_TRANSFERRED` | program 의 명령·주소·**데이터** 전송 끝 | 채널 IDLE, 칩 WRITING |
| `ERASE_SETUP_COMPLETED` | erase 명령 전송 끝 | 채널 IDLE, 칩 ERASING |

read 만 **완료 후에 채널을 한 번 더** 쓴다(데이터가 칩 → 컨트롤러로 나와야 하니까). program 은 데이터를 **먼저** 보낸다. 이 비대칭이 "채널 하나에 칩 여러 개" 구조의 효율을 좌우한다.

### 시간표의 구성 요소

- **전송 시간**: `ONFI_Channel_NVDDR2` 생성자가 `t_CS`, `t_WC`, `t_WB`, `t_RR`, `t_DBSY` … 같은 ONFI 타이밍 조합으로 `ReadCommandTime[plane 수]`, `ProgramCommandTime[…]`, `EraseCommandTime[…]` 를 만든다. plane 수가 늘면 조금씩 길어진다.
- **데이터 전송**: `NVDDR2DataInTransferTime`(program)과 data-out(read)은 byte 수 ÷ 채널 속도(`Channel_Transfer_Rate`, 기본 333 MT/s)다.
- **실행 시간**: `Get_command_execution_latency()`(`Flash_Chip.h:85`) = 연산 지연 + R/B 신호 지연. **멀티플레인 명령의 실행 시간은 단일 연산 한 번의 시간**이다.

PHY 의 `Send_command_to_chip()` 이 `SuspendRequired` 인 명령을 받으면 `Suspend()` 를 부르고(program 은 `ProgramSuspendCommandTime + GetSuspendProgramTime()`, erase 는 erase 쪽 값만큼의 지연을 시간에 더한다), read 가 끝나 칩이 한가해지면 `send_resume_command_to_chip()` 이 `Resume()` 을 부른다. `Flash_Chip::Suspend` 는 남은 시간을 저장하고 완료 이벤트를 **무효화**(`Ignore_sim_event`)하며, `Resume` 은 새 완료 이벤트를 예약한다(`Flash_Chip.cpp:203`, `:234`).

> **원본에서는 이 경로가 도달 불가능했다.** TSU 의 `switch` 가 `suspensionRequired = true` 뒤에 `break` 없이 `default: return false` 로 떨어졌고, 그 밖에 인자 순서 · 카운터 복원 등 결함이 겹쳐 있었다. 자세한 기록은 [명령 서스펜드가 한 번도 작동한 적이 없던 버그](/ftl-visual-simulator/reference/code-change/bug-list/suspend-resume-deadlock-bug/).

## 4. 이 프로젝트에서의 의미

- 시뮬레이터의 **읽기 지연** 차트와 "명령 일시정지(suspend)" 설정이 이 페이지의 장면이다. erase 한 번이 3.8ms 동안 die 하나를 점유하기 때문에 GC 가 읽기를 느리게 하고, suspend 가 그 꼬리를 줄인다.
- **Copyback**(`Use_Copyback_for_GC`)은 GC 의 page 이동을 컨트롤러로 내보내지 않고 칩 안에서 하는 방식이다. 기본은 꺼짐이고, 켜면 GC 의 read/write 쌍이 `COPYBACK` 명령이 된다.
