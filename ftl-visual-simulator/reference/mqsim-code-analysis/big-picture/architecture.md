FTL 을 이해하는 데 필요한 대부분은 `ssd/` 안에 있다. `host/`, `exec/`, `sim/` 은 "SSD 를 돌리기 위한 무대"이고, `nvm_chip/` 은 NAND 가 어떻게 생겼는지만 담은 얇은 층이다.

## 2. 파이프라인 한 줄

`SSD_Device.h` 의 주석이 구조를 그대로 말해 준다.

```
Host_Interface <-> Data_Cache_Manager <-> NVM_Firmware (FTL) <-> NVM_PHY <-> NVM_Channel <-> Chips
```

이웃한 두 계층끼리만 대화한다. 호스트 인터페이스가 칩을 직접 부르는 일은 없다.

| 종류 | 예 | 특징 |
|---|---|---|
| **소유·포인터** | `SSD_Device` → 부품들, `FTL` → 4부품 | 객체를 만들 때 한 번 연결. 직접 호출에 쓰인다 |
| **신호(콜백)** | `PHY` 가 "트랜잭션 완료" 를 방송 → AMU · GC/WL · 캐시 · TSU 가 각자 받음 | `Setup_triggers()` 에서 한 번 연결. 위로 올라가는 완료 통지에 쓰인다 |

신호 연결표는 [이벤트 엔진과 시간](/ftl-visual-simulator/reference/mqsim-code-analysis/big-picture/event-engine/)에 있다.
